# Libft

A custom C library developed as part of the 42 curriculum.

Libft is a foundational project focused on recreating standard C library functions while building a deeper understanding of memory management, string manipulation, linked lists, and low-level programming concepts.

The objective was to develop a reusable library of utility functions that would later serve as the foundation for future projects.

---

## 🧠 What I Learned

Working on Libft provided practical experience with:

- Memory management
- Pointer manipulation
- String handling
- Dynamic allocation
- Linked lists
- Modular programming
- Code reusability
- Defensive programming
- Low-level C programming

---

## ⚙️ Features

### ✅ Standard Library Functions

Reimplemented common libc functions including:

- `memset`
- `bzero`
- `memcpy`
- `memmove`
- `strchr`
- `strncmp`
- `atoi`
- `calloc`
- `strdup`

### ✅ Additional Utility Functions

Custom utility functions such as:

- String splitting
- String trimming
- Integer to ASCII conversion
- String joining
- String mapping/iteration

### ✅ Linked List Utilities

Implemented a complete linked list API:

- Node creation
- Node insertion/removal
- List iteration
- List mapping
- Memory cleanup
